# Mi Perfil Dev

## Getting Started

Mini aplicación desarrollada con Flutter

## Tecnologías

- Dart
- Flutter

## Funcionalidades 

- Pantalla principal con información del desarrollador.
- Lista de habilidades/tecnologías favoritas.
- Segunda pantalla con el listado completo de tecnologías.
- Navegación entre pantallas.
- Tocar una skill la marca/desmarca como favorita.
- El botón de la paleta en el AppBar cambia el color de la app.

## Probar

```bash
flutter pub get
flutter run
```
